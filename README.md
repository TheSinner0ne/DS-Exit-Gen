# DS-Exit-Gen
DS Exit Gen is a simple tool that help, DroidScript User, especially those making HTML App to create a simple exit dialog with customization and supports HTML rendering with great navigation for HTML apps that helps navigate homepage which avoid 1x press back exit directly.

## Feature
- Custom Icons For Exit Dialog support FontAwesome, Remixicon Icons and Image
- Customizible Exit Dialog backround, support solid color and gradiants
- More Customization - Ex. Border Radius, Colors and More
- With Live Preview - 100% not Accurate
- Purely Offline
- Custom Dialog Text
